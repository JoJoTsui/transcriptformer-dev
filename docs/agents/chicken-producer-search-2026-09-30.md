# Chicken producer-record follow-up, 2026-09-30

Scope: ticket 04's checkpoint annotation provenance and the GRCg6a-to-GRCg7b row-level bridge. This is a bounded follow-up to the [closure gate](chicken-closure-gate-2026-09-29.md); it does not alter accepted mappings.

## Additional producer paths checked

1. The producer's [Virtual Cells quickstart](https://virtualcellmodels.cziscience.com/quickstart/transcriptformer-quickstart) lists `gallus_gallus_gene.h5` among the precomputed embeddings, at 180,101,052 bytes in its example archive listing. It describes the bundle as approximately 4.8 GB compressed, but gives no chicken input FASTA, assembly, annotation release, build command, or output checksum. The file listing's April 6 timestamp cannot identify an Ensembl release. It does corroborate that the chicken embedding was distributed with the early bundle.
2. The producer's [changelog](https://github.com/czi-ai/transcriptformer/blob/main/CHANGELOG.md) dates the public ESM-2 preprocessing pipeline to version 0.5.0, 2025-08-11 ([commit `181193c`](https://github.com/czi-ai/transcriptformer/commit/181193c)). That is later than the [initial public code](https://github.com/czi-ai/transcriptformer/commit/241fa55) and the early embedding bundle. The current [release-113 FASTA manifest](https://github.com/czi-ai/transcriptformer/blob/181193c/preprocess/fasta_manifest_pep.json) therefore remains a reproducible *later* recipe, not a build record bound to the released HDF5.
3. I inspected all locally fetched public upstream branch trees and the pre-pipeline commit history for producer preprocessing manifests or chicken-specific records. Before `181193c`, the public trees contain the chicken validation H5AD and reference inference H5AD, but no chicken FASTA manifest or protein-embedding build script. `git log --all -S 'gallus_gallus_gene.h5'` and `-S 'GRCg6a'`, excluding this project's documentation, found no producer-origin annotation statement. This is a statement about the fetched public refs only, not inaccessible internal records.
4. A metadata-only HDF5 inspection of the two shipped examples found no producer release field. `test/data/chicken_val.h5ad` (SHA-256 `54eef2845dd9c2f2c07092ee500116258be38c261dcc218105ccd8c08d851aab`) has empty `uns`, and its `var/feature_reference` only identifies taxonomy `NCBITaxon:9031`. `test/data/reference_embeddings/embeddings_metazoa_chicken.h5ad` (SHA-256 `3440354a257f0828221e50f924bde7b680de6faccd359124797918ad41345981`) has only `uns/llh`; neither file has a FASTA, assembly or Ensembl release in root or `uns` attributes. The exact checkpoint HDF5 itself was previously checked for attributes in the [provenance audit](chicken-identifier-provenance-2026-09-28.md).
5. Targeted searches of the producer's public repository, issues, model quickstart and exact HDF5 filename did not reveal a producer-bound build record or a release-bound GRCg6a/GRCg7b row-level export. The public [README](https://github.com/czi-ai/transcriptformer/blob/main/README.md) confirms chicken model support but names no source annotation release.

## Result

No new producer-bound provenance or accepted cross-assembly rows were found. The existing 7,267-row strict bridge remains partial. The checkpoint key and protein-content equivalence among GRCg6a releases 99/100/101/106, and the 9,611 unresolved keys, remain exactly as stated in the [closure gate](chicken-closure-gate-2026-09-29.md). The next decisive input is the producer's original build manifest/log bound to checkpoint HDF5 SHA-256 `ff5d5f03e074e267a4ec4ed63f5f805e20e9f3f95f94d1e547b4e90115f874f9`, or a scientific-owner decision to record the release as unknown and adopt the equivalence-class description. Expanding the bridge additionally requires reviewed row-level cross-assembly evidence.
