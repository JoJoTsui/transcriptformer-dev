# Three chicken Table 12 candidate pairs

Date: 2026-09-29. Ticket 04. This review concerns only publisher Table 12 rows 9416, 32617 and 45964. It does not change the accepted bridge.

## Evidence and limits

The [publisher's Table 12](https://static-content.springer.com/esm/art%3A10.1038%2Fs41598-024-56705-y/MediaObjects/41598_2024_56705_MOESM15_ESM.xlsx) proposes the three old-to-new Ensembl pairs below. The [existing audit](chicken-conflict-review-2026-09-29.md) independently recovered a shared NCBI GeneID from archived Ensembl release-106 GRCg6a and release-110 GRCg7b core exports, but the `DIRECT` RefSeq accessions differ (row 45964's new association is `SEQUENCE_MATCH`). A bounded scan of those archived `gene`, `xref`, `object_xref` and `external_db` exports found **exactly one gene per GeneID in each release** for all three GeneIDs. I queried the six official Ensembl `/lookup/id/{id}?expand=1` records and their protein `/sequence/id` records on this date, using only these IDs. The old lookup records currently resolve under Ensembl's GRCg6a alternative assembly; the new records resolve under GRCg7b. The REST service is live, so its current gene models are **corroboration**, not a frozen release-106/110 history export or evidence of which annotation produced the TranscriptFormer checkpoint. [Ensembl stable-ID documentation](https://jun2026.archive.ensembl.org/info/genome/stable_ids/index.html) describes how IDs are propagated across annotation changes.

The [official NCBI Gene summary endpoint](https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=gene&id=430939%2C771070%2C419495&retmode=json) independently returns SH3BP1, KXD1 and FBXO2 for those three GeneIDs. The current NCBI Gene pages and current Ensembl REST records can change; the archived-core GeneID associations and [publisher-bound candidate TSV](../chicken-published-table12-candidates.tsv) are the release-bound part of this review. The r106 old peptide for FBXO2 is in the official [Ensembl release-106 archive](https://ftp.ensembl.org/pub/release-106/fasta/gallus_gallus/pep/Gallus_gallus.GRCg6a.pep.all.fa.gz); the new peptide comes from [Ensembl REST](https://rest.ensembl.org/sequence/id/ENSGALP00010030607?content-type=text%2Fplain).

**Decision:** no automatic mappings. Row 45964 now has exact peptide and exon-chain support; row 32617 has near-identical peptide and exon-length support; row 9416 has shared GeneID and substantial exon/protein continuity with an assembly caveat. There is no competing *GeneID-linked* target in either archived core for these three pairs, but that does not exclude competing genes without the GeneID xref. A separately specified, release-bound acceptance rule and that wider competing-target check would be needed before any bridge expansion. The checkpoint's exact chicken annotation source remains open.
