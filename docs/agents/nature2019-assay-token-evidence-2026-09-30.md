# Nature2019 candidate: assay token evidence — 2026-09-30

**Recommended existing checkpoint token: `Smart-seq2` (ID 20), for the RNA count matrix only.** This is a source-backed normalization proposal, not a decision to add the source to the training corpus.

The [study's Methods, “scNMT-seq library preparation”](https://www.babraham.ac.uk/sites/default/files/2020-09/31827285.pdf) say poly-A RNA was captured on oligo-dT magnetic beads and amplified cDNA was prepared according to G&T-seq and Smartseq2 protocols. The same section says the scRNA-seq-only subset followed the same protocol with genomic DNA discarded after separation. Thus the RNA libraries in both the multi-omics and RNA-only subsets share a Smart-seq2-based preparation. The methods describe RNA gene counts quantified with featureCounts, separate from methylation and accessibility outputs. Calling the **RNA expression matrix** `Smart-seq2` preserves the library method that the model's assay token represents; it does not claim every cell was RNA-only or erase the source's scNMT-seq multi-omics provenance.

The actual local TF-Metazoa checkpoint file `checkpoints/tf_metazoa_finetuned/vocabs/assay_vocab.json` (symlink to `/mnt/d/sc/transcriptformer/checkpoints/tf_metazoa/vocabs/assay_vocab.json`, SHA-256 `0c405e4ead45a4b8350d8e874f834273efdd3f7ad4669b52d3e3727fb4fe70af`) has 40 entries: `Smart-seq2: 20`, `Smart-seq: 5`, `mCT-seq: 19`, and `unknown: 0`. It has no `scNMT-seq` entry. [`BatchObsTokenizer`](../../src/transcriptformer/tokenizer/tokenizer.py) does exact string lookup and maps missing labels to `unknown`; `scNMT-seq` or variant capitalization would therefore lose the specific assay signal. [`prepare_dataset_file`](../../src/transcriptformer/finetune/prepare.py) requires `assay` in `obs` but does not normalize it, so the candidate source must carry the exact string if included.

Do not use `mCT-seq` merely because this source is multi-omics: the study identifies the RNA library method as Smartseq2, and the present candidate H5AD is an RNA count matrix. Keep `native_assay=scNMT-seq` (or equivalent provenance) separately from the normalized model token. The source inclusion decision, non-UMI QC, mixed-embryo disposition, cell-type/phase mapping, and final corpus freeze remain independent gates; see the [source suitability audit](nature2019-source-suitability-2026-09-29.md).
